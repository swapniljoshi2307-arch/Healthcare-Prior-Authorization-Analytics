# Healthcare-Prior-Authorization-Analytics
Healthcare Prior Authorization Analytics Dashboard using Power BI
Healthcare Prior Authorization Analytics | Power BI

Project Overview

An interactive Power BI dashboard built to analyze healthcare prior authorization data, focusing on authorization outcomes, payer performance, therapy areas, denial patterns, and turnaround times.

Key Performance Indicators

Total Authorizations: 350

Approval Rate: 80.1%

Denial Rate: 19.9%

Approved Authorizations: 245

Denied Authorizations: 61

Pending Authorizations: 36

Average Turnaround Time: 4.1 Days

Dashboard Features

Authorization volume by urgency

Authorization distribution across therapy areas

Monthly authorization submission trends

Payer-wise authorization analysis

Average turnaround time by payer

Denial analysis by reason

Authorization status distribution

Interactive payer and therapy-area filters

Tools & Technologies

Microsoft Power BI Desktop

Power Query

DAX

Data Visualization

Dataset

A fictional healthcare prior authorization dataset created for educational and portfolio purposes.

Objective

To demonstrate analytical and data visualization skills through healthcare operational data, identifying trends in authorization outcomes, payer performance, and processing efficiency.

Disclaimer
